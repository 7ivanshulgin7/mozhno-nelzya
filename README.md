# Можно или нельзя

Помощник на время крапивницы: продукты (можно / осторожно / нельзя), дневник сыпи, памятка по лекарствам.
Статический сайт на GitHub Pages, ставится на телефон как приложение.

- Дневник хранится только на телефоне (localStorage). Сервера и базы нет.
- «Сохранить копию» — файл `.json` с записями; «Загрузить копию» — вернуть их (на новом телефоне или после сброса).
- Работает без интернета после первого открытия (`sw.js`).

## Файлы для загрузки на GitHub

`index.html`, `manifest.json`, `sw.js`, `icon-180.png`, `icon-192.png`, `icon-512.png`, `README.md`.
`make-icons.ps1` — рисует иконки, загружать не нужно.

## Как обновлять

1. Поправить `index.html`, поднять версию внизу страницы (`v1.0`).
2. В `sw.js` поднять `CACHE` (`mn-v1.1` и т. д.).
3. Загрузить на GitHub оба файла с заменой. Телефон подхватит при следующем открытии с интернетом.
